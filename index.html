SLIDE 01 · 리서치 개요 임팩트 장표
숫자로 신뢰를 먼저 잡는다
6,540 / 33 / 30명+ 3개 숫자를 크게 중앙에 배치. 배경은 풀솔리드 다크, 레드 강조. 텍스트 최소화하고 숫자만 남긴다.
시각화 요소
대형 KPI 숫자 타임라인 바 리서치 방법 아이콘
PPT 팁 — 숫자 폰트 80~100pt. 단위(건, 명)는 20pt로 작게. 좌측 정렬 금지, 중앙 정렬로 임팩트.
SLIDE 02 · 설문 결과 데이터 장표
가로 막대 + 한 줄 인사이트
불편 순위를 가로 막대그래프로. 1위 항목만 레드 강조. 나머지는 그레이. 각 막대 옆에 인사이트 한 줄 텍스트 붙이기.
시각화 요소
가로 막대그래프 파이차트 (기기) 인사이트 콜아웃
PPT 팁 — 모든 막대를 같은 색으로 쓰지 말 것. 핵심 1~2개만 레드, 나머지 #333. 퍼센트 숫자는 막대 끝에 인라인으로.
SLIDE 03 · 핵심 인사이트 핵심 장표
2×2 카드 + 인터뷰 발화 인용
인사이트 4개를 2×2 카드 그리드로. 각 카드 좌상단에 인터뷰 발화 이탤릭 인용. 하단에 데이터 출처 배치. 제목은 "행동 동사"로 시작.
시각화 요소
2×2 카드 그리드 인터뷰 인용 quote 데이터 배지
PPT 팁 — 카드 배경 #141414. 좌측 상단 컬러 라인 4px로 인사이트별 구분. 텍스트 계층 3단계 (인용→제목→설명) 유지.
SLIDE 04 · 문제 분류 판단 장표
5열 카드 + 컬러 분류
5가지 문제를 나란히 카드로 배치. "바로 설계" 카드는 그린 테두리, "UT 필요" 카드는 레드 테두리+강조 배경. 시각적으로 즉시 분류.
시각화 요소
5열 카드 레이아웃 컬러 코딩 분류 VOC 건수 숫자
PPT 팁 — 카드 하단에 화살표 → UT 진행으로 흐름 연결. 테두리 두께 차이로 위계 표현 (UT 필요 = 2pt, 나머지 0.5pt).
DESIGN RULES FOR PPT
1장 1메시지 — 제목이 곧 결론이어야 합니다. "설문 결과"가 아니라 "48%는 관성으로 남고, 한 번에 떠난다"처럼.
레드는 1~2곳만 — 티빙 레드(#FF153C)는 포인트에만. 전체에 뿌리면 강조가 사라집니다.
숫자는 크게, 설명은 작게 — 6,540 / 67.7% 같은 핵심 숫자는 80pt+, 부연 설명은 14pt 이하로.
배경 통일 — 전 장표 #0D0D0D 다크 배경 유지. 중간에 화이트 배경 섞으면 브랜드 톤이 끊깁니다.
인용은 이탤릭으로 — 인터뷰 발화는 반드시 " " + 이탤릭 + 그레이 컬러. 데이터와 발화를 시각적으로 구분.
출처 배치 필수 — VOC 527건 / 설문 39.4% 처럼 모든 수치 옆에 출처 배치. 신뢰도가 포트폴리오 퀄리티를 결정합니다.
